# Flash VSIX

Flash navigation for Visual Studio Code and compatible forks, designed to work alongside Vim and Neovim extensions.

> This repository is a work in progress.

## Overview

Flash aims to bring quick, label-based navigation to VS Code editors while supporting workflows that use Vim- and Neovim-style extensions.

## Status

The project is in its early stages. Installation instructions, usage details, and supported editor versions will be added as they become available.
